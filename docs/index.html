The revival

MongoHub is back, on a modern Mac.

MongoHub was a well-loved Mac client for MongoDB from 2010 to 2015, created by Syd Xu and later maintained by Jérôme Lebel. It was abandoned a decade ago. It targets OS X 10.8, runs on Intel only, and no longer builds on any current Mac.

MongoHub Plus is a from-scratch rewrite with the same window layout and workflows. If you used MongoHub, you'll know where everything is. Underneath it's new: Swift 6, AppKit and the pure-Swift MongoKitten driver.

  • Native, not a web viewSwift 6 and AppKit, with system dark and light appearance and the keyboard shortcuts you expect.
  • Universal, signed, sandboxedOne download for Apple Silicon and Intel. Developer ID-signed, notarized by Apple, and runs in the App Sandbox.
  • Your data stays exactKey order and BSON types are kept end to end. Edits are verified byte by byte, so a Decimal never quietly turns into a Double.

Features

Everything you do with MongoDB, in one native app.

The original's full toolset is here, plus features it never had.

MongoDB Atlas New

mongodb+srv:// seed lists, TLS and SCRAM auth. Paste a connection string and go. Replica sets, sharded clusters and SSH tunnels work too.

Find, insert, update, remove

Query history, projection, sort and paging. The Update tab previews the matched documents with the change marked before you run it.

Aggregation builder New

Build pipelines stage by stage: drag to reorder, toggle stages on and off, and preview the results after any stage. Switch to text at any time.

Explain plans New

One click on any query or pipeline shows whether it used an index or scanned the collection, with execution stats and index suggestions.

Edit with type fidelity

Edit values in place in the results tree, or in a syntax-colored JSON editor. Every save is round-trip checked so types never change silently.

Live change-stream Tail New

Watch inserts, updates and deletes arrive on a collection in real time, on replica sets and Atlas.

Index insight

Create and drop indexes, see each one's size and usage count, and spot the ones that have never been used.

Import & export

JSON Lines in canonical Extended JSON, spreadsheet-friendly CSV, and BSON folders that mongorestore reads directly.

Six languages

English, 日本語, Deutsch, 繁體中文, 简体中文 and Français, switchable in Settings. Updates arrive automatically through Sparkle.

Aggregation

See every stage of your pipeline.

Pick a stage and the preview shows the documents as they leave it. Find the stage that drops your data without copying the pipeline into a shell.

Explain

Know if your query uses an index.

The verdict comes first: index scan or collection scan. Below it are the winning plan, documents examined against returned, and an index suggestion when one would help.

Connections

All your clusters, one window.

Local servers, Atlas, replica sets and sharded clusters side by side. Pin favorites and search by name. Passwords live in the macOS Keychain, never in a settings file.

Queries

Type queries the way you already do.

Paste official MongoDB Extended JSON straight from Compass or mongoexport, or type mongosh shorthand with unquoted keys and ObjectId(…). Mix them freely. Paste a bare id and it looks up that document.

Exports are always standard Extended JSON, so Compass, mongoimport and every driver can read them. Full syntax reference

FAQ

Questions

Is this the original MongoHub?

No. It's a new app written from scratch that follows the original's design and workflows. The original MongoHub hasn't been updated since 2015 and doesn't run on current macOS. MongoHub Plus continues its version line from 4.0.

Does it work with MongoDB Atlas?

Yes. Paste your mongodb+srv:// connection string from the Atlas console. TLS and SCRAM authentication are supported, and change-stream Tail works on Atlas clusters.

Which MongoDB versions are supported?

MongoDB 6.0 and later are supported and tested. Older servers may work but aren't tested.

Does it run on Apple Silicon?

Yes. The app is a universal binary that runs natively on both Apple Silicon and Intel Macs with macOS 14 or later.

Is it free? Where is my password stored?

It's free and open source under the MIT license. Connection passwords are stored in the macOS Keychain, and the app runs in Apple's App Sandbox.

How does it compare with MongoDB Compass?

Compass is MongoDB's own cross-platform app built on Electron. MongoHub Plus is a native Mac app, so it's smaller and starts quickly, and it reads and writes the same Extended JSON that Compass does.
